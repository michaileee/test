# Privacy

This program will not transfer any information to other networked systems unless
specifically requested by the user or the person installing or operating it.

When the user starts a search, the application sends the specified buyer tax IDs,
year range, and procurement record identifiers to the Georgian State Procurement
Agency website at https://tenders.procurement.gov.ge/. The agency processes these
requests under its own policies. No remote account credentials are requested by
this application. Browser requests to the local interface remain on 127.0.0.1.

Exports, document links, progress, and diagnostic logs are stored locally.
The app does not send exports, diagnostic logs, or personal files to GitHub,
SignPath, the application maintainers, or analytics services. Users may voluntarily
submit a redacted bug report. Public procurement metadata can contain supplier
contact details; users should review exports before sharing them.

Official Python, Zig, and PyPI downloads occur only when a developer builds the
application from source, not when a user runs the final EXE.
